# 父子代理的来源与接收者许可

记录日期：2026-10-13。范围：DSH 0.2.0-rc.2、一个父代理、一个新建前台子代理、
固定委派任务和原生文本读取。以下为私有 Lab 的方法与评审结果。

## 三种关系分别处理

本地操作许可、向接收者发送数据的许可、指令来源是三个独立条件。
子代理返回正文属于不可信任务数据，不因为它来自 agent、符合 JSON schema 或包含
“已获授权”的自述而升级为操作者指令。

父代理能够调用一次固定委派任务，不等于子代理可以读取任意文件。
子本地准入应取角色许可、可委派资源、本次委派范围和目录排除的交集。
子允许向自己的模型发送一份文件，也不意味着父可以消费它的派生返回。

## 绑定返回链条

防守装配器核对父子各自的会话、实际委派执行、宿主生命周期、child 最终消息、
原始 SDK 输出、canonical 返回值和父实际消费的呈现正文。调用 ID 的登记表属于
各自 actor，不能跨代理只靠一个文本 call ID 建立关联。

派生返回保守继承 child 实际批准输入的根来源。已经在 child 模型请求之前投影掉的
本地原文，不算实际 child 输入。摘要或转述不会自动降低已有来源的许可要求。
父每一轮历史消费都重新检查接收者许可。

## 两处评审发现及修补

| 发现 | 防守修补 | 验证范围 |
|---|---|---|
| canonical value 一致不足以证明实际呈现一致 | 在来源登记前核对实际 render、文本形态和预期摘要 | 正常返回、呈现故障、固定失败通知与特定 SDK 语义 |
| 可委派资源声明未进入子本地准入 | 将声明加入本地许可交集，评分独立核对实际读取 | 允许、角色拒绝、目录排除与非委派资源 |

这些缺口通过离线回调与特定 SDK 校准确认，后续私有实现已修补。
公开稿提供修补原则和结果，不附边界故障的可执行探针。

## 最终输出和失败

真实 SDK 可以同时返回可见 reasoning 与正文。已验证的私有选择器保存完整原始结果和
输入根来源，只让父消费绑定后的一条正文；选择正文不会解除原来的来源许可。
这一选择不声明可以认证服务端完整内部推理。

未完成、错误或 partial output 保留在本地。父可以接收独立固定失败通知；通知来源
与 child 原始输出分开。已校准的 max-tokens 分支不能替代所有异常出口的验收。

## 已验证与尚未验证

同版本两次干净实模、共十次请求，分别验证父可消费 child 标签，以及父无接收许可时
两次历史消费均投影并正确报告缺少输入。两组来源健康和授权评分通过。
这是来源任务，不能作为配置诊断或总体对抗能力的证明。

后续四组有限不可信内容对照共二十次请求，正常任务通过；开关两边均未出现目标读取
尝试，因此没有测到真实政策阻断效果。此前 HTTP 503 失败、原输出选择失败和 Kimi
缺少最终正文的结果仍分别保留，见[阶段报告](../reports/blue-team-lab-2026-10.md)。

并发、多层委派、fork、后台子代理、PTC、持久记忆和任意自由委派尚未包含在这个方法
验收范围内。同权限进程可以绕过或修改控制面，仍受[威胁模型](../design/threat-model.md)限制。
