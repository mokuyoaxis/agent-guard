Workspace Doctor Unicode sequence data

The bundled table is derived from Unicode 17.0 sequence and joining data
and the registered Adobe-Japan1 collection of the Unicode Ideographic
Variation Database. The table contains only sequence and joining facts.

E rows are Emoji ZWJ and RGI tag sequences. V rows are variation
sequences. J rows are joining type ranges. Code points are hexadecimal.
